Following Retail's pattern — orchestrator functions per stage, plus per-feature subpackages:

Each orchestrator follows the same pattern as Retail's generate_master_data / generate_customer_data:

Resolve seed from config
Generate datasets in dependency order
Order them according to the registry
Return a frozen dataclass with datasets, seed, row_counts(), total_rows()
