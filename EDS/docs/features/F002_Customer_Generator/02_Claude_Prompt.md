## Ambiguity resolved without escalation

The specification defines the datasets, distributions, and rules concretely
enough to implement directly. Two points needed a decision and were resolved
in line with the stated principles rather than escalated:

1. **How F002 obtains F001 output.** "Consume the datasets generated by F001,
   do not regenerate master data" was read literally: the generator reads the
   exported Parquet files from the output directory. The alternative -
   regenerating master data in memory - would contradict the instruction.
2. **The meaning of "deterministic" for date-bearing data.** Registration and
   birth dates need an anchor. Using today's date would make a seeded run
   produce different data tomorrow, so a configurable `reference_date` was
   added rather than calling `date.today()`.

Both are recorded as assumptions in `03_Review.md`.
